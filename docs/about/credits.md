# Credits

## Sources

* The starting point for this project is code generate with SMT32CubeMx and the SMT32 LL (Low Level) libraries.
    * [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html).
    * [STM32f4xx HAL](https://github.com/STMicroelectronics/STM32CubeF4)
    * [STM32CubeF4 repository](https://github.com/STMicroelectronics/STM32CubeF4)
* The formatting using for this project is taken from the .clang-format file proposed by YodaEmbedding
    * [repository](https://gist.github.com/YodaEmbedding/c2c77dc693d11f3734d78489f9a6eea4)
* The documentation is generated using [MkDocs](https://www.mkdocs.org/) with the [Material theme](https://github.com/squidfunk/mkdocs-material) with [mkdoxy](https://github.com/JakubAndrysek/mkdoxy) to add the [Doxygen](https://www.doxygen.nl/) generated documentation.
